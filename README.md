## 写作纪律

这些报告用于竞争情报、招聘背调与行业研究，写作上遵循几条固定规则：

- **事实分层** —— 每条关键信息归入「已核实（附一手链接）/ 未核实存疑 / 未能获取」，未获取的写明障碍是什么。
- **口径冲突并列** —— 同一件事有多套口径时全部列出并说明各自衡量什么。MAU 与 ARR 常常指向相反结论，用错会得出反向判断。
- **区分「宣布」与「完成」** —— 签署、交割、上线、灰度、预计，时间状语分别标注。
- **隐私边界** —— 只采用本人公开发布的职业信息（姓名、雇主、教育、研究方向、公开主页），不含任何电话、微信等联系方式。
- **不继承搜索摘要的评判** —— 搜索结果的自动摘要常带「掉队」「跑出来了」这类结论，一律回到一手数据验证；拿不到就明写「未能获取」。

## 使用提醒

报告中的 ARR 均为**年化运行率**口径、非审计收入；用户数据除注明外均来自第三方监测机构（QuestMobile、IDC、易观等），非各公司官方披露。所有判断都有边界，引用时请连同口径与时间一起引用。
