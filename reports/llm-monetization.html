大模型怎么赚钱

11 家公司、六种收钱方式、一条被反复误读的价值链。这份报告不比较谁的模型更强，只回答一个问题：每一家的钱，具体是从谁的口袋、以什么名义、按什么单位收上来的——以及为什么收入在涨，利润却还没有出现。

结论先行

  1. 这 11 家在卖六种不同的东西，计价单位都不一样，混在一起排名次比的是会计口径，不是竞争力。席位、Token、算力、项目、生态、内部提效——同一家公司往往同时用几种。按收入规模排 OpenAI 和云厂商在前，按毛利率排卖 Token 的在前，按现金流排反而是「不单卖」的腾讯最从容。
  2. 价值链的分配比模型能力更能解释这个行业：模型公司每赚 100 美元，35–40 美元以推理算力费的形式流向云厂商。巴克莱 2026-08 的拆解显示，云厂商从这部分收入里拿到 10–20 美元营业利润，对应 35%–45% 的营业利润率。模型公司在替云厂商打工，而且是自己投资的那几家云厂商。
  3. 最反直觉的一组数字：API 的推理利润率超过 80%，高于订阅的约 70%。订阅是包月定价，重度用户会吃掉利润；API 按量计费，成本可以完整转嫁。这直接推翻了「订阅更稳更值钱」的常识，也解释了下面第 5 条。
  4. 毛利率才是真正的分水岭，而排名出人意料。DeepSeek 的 API 毛利率 82.9%，高于 OpenAI 的整体毛利率（2026 Q1 约 39%）、智谱（2026H1 26.4%）、MiniMax（2026H1 17.9%）。定价最低的那家，单位经济性最好——差距不在定价，在推理成本。
  5. 前沿实验室里，做纯 B2B API 的 Anthropic 比做 C 端订阅的 OpenAI 先摸到盈亏平衡。Anthropic 毛利率从 2024 年的 −94% 修复到 2026 年的约 60%，Q2 录得首笔营业利润约 5.59 亿美元，Q3 预计 GAAP EBIT 超 10 亿美元。而 OpenAI 2026 年预计经营亏损 140 亿美元，每赚 1 美元亏 1.22 美元，预计 2030 年才盈利。差别不在技术，在收入结构——以及 9 亿免费用户的成本。
  6. 云厂商的「AI 收入暴涨」里，有相当大一块是循环交易，不是终端需求。机制是：云厂商投资实验室 → 实验室拿钱承诺采购该云厂商算力 → 云厂商把采购承诺计入积压订单。谷歌云 5,140 亿美元积压订单里，Anthropic 一家占 2,000 亿美元（40%+），而谷歌同时是 Anthropic 14% 的股东、承诺投资至多 400 亿美元、芯片还指定为自家 TPU。
  7. 唯一「账算得过来」的一类，是把 AI 藏进已有业务、不要求它独立盈利的。腾讯把 AI 塞进游戏（单季 659 亿元）和广告（435.7 亿元），Google 塞进搜索与广告。它们不需要回答「AI 业务什么时候盈利」，因为 AI 的作用是让主业更快。这可能是这个行业里最被低估的一种优势。
  8. 中国有一条别人没有的路径，也正在主动放弃它。智谱 FY2025 有 73.7% 收入来自私有化部署（毛利率 48.8%）；2026H1 它把这条线砍到只剩 7%，换来了 API 收入 +2,735.7%——代价是整体毛利率从 50.0% 腰斩到 26.4%。用低毛利换高增长不是升级，是换轨。
01 / 收钱方式

六种收钱方式，和它们各自的计价单位

把「大模型公司」当成一个行业来比高低，是最常见的读法错误。拆开收入结构就会发现，这 11 家其实在卖六种不同的东西——计价单位都不一样，硬放在一张表里排名次，比出来的是会计口径，不是竞争力。

为什么这个分类重要

因为「谁更成功」的答案完全取决于你问的是哪一种。按收入规模排，OpenAI 和云厂商在前；按毛利率排，卖 Token 的在前；按现金流排，反而是那个「不单卖」的腾讯最从容。把六种方式混在一起谈「大模型赚不赚钱」，永远得不出结论。

一个被忽略的第七种：Agent 抽成

还有一类正在成形、但截至数据截止日还没有人跑通的方式：按任务或按席位对 Agent 的工作流收费。它的计价单位既不是 Token 也不是席位，而是「完成的任务」。中金在单位经济模型里指出，Agent 相比传统 Chatbot，输入 Token 占比显著更大、总消耗量是 Chatbot 的几十甚至上百倍——这意味着 Agent 即使单价更低，总账也更大。

但这门生意的收入归属还没定：目前 Agent 消耗的算力账单算在云厂商头上，Agent 产品本身收不到这笔钱。这正是大厂做 AI 办公产品的真实动机（见第 05 节）。

02 / 价值链

钱在谁手里：一条被误读的分配链

这一节回答一个具体问题：大模型公司收上来的每一百块钱，最后有多少真的留在了自己手里。两家投行的拆解给出了接近的答案，但口径并不一致——这个不一致本身，就是理解这个行业的关键。

巴克莱：每 100 美元收入，35–40 美元流向云厂商

这条拆解里最值得记住的是最后两个数字的反差：订阅的推理利润率（约 70%）低于 API（超 80%）。这和大多数人的直觉相反——通常认为订阅收入更稳、更值钱。原因是订阅是包月定价，重度用户的推理成本会吃掉利润；而 API 按量计费，用多少付多少，成本可以完整转嫁。

巴克莱说推理利润率 50%–65%，中金说实际毛利率 40%–50%。两个数字不矛盾，但衡量的是不同的东西：巴克莱算的是推理业务本身的利润率（不含训练成本分摊、不含总部费用）；中金算的是含训练摊销的毛利率。中金自己给的理论上限 60% 也高于实际值 40%–50%——差额就是训练成本与工程损耗。

引用时必须连口径一起引用。单独说「大模型毛利率 60%」是不成立的。

两个成本侧的结论

第一，自建比租赁省不了太多。自建 2 美元 vs 租赁 2.6 美元每百万 Token，差距约 23%。这意味着自建算力的意义不在单位成本，而在供给确定性——能拿到卡比省下的钱重要得多。这也解释了为什么各家即使亏损也要自建数据中心。

第二，推理效率才是真正的杠杆。中金明确指出「推理端的 Tokens 输出效率是决定综合成本的核心因素」，并给了一个参照：英伟达 B200 在 gpt-oss（120B 小模型）上可达 60,000 Tokens/s，而万亿参数模型在同样硬件上只有 1,000 Tokens/s。参数规模小、专注推理优化的国产厂商，在同等算力卡上有更优的推理效率——这是国产模型敢打价格战的底层原因，而不只是「烧钱补贴」。

中国模型的价格折价：5%–30%

中金给出了一组对理解中国大模型商业化至关重要的数字：国产模型 API 定价整体在对标海外模型的 5%–30% 不等。虽然国产模型推理成本也低，但降本幅度追不上降价幅度，所以「国产模型毛利水平整体还是低于海外模型」。

中金同时认为国内头部与海外头部模型的能力动态差距在 6–9 个月，随能力追赶和 Agentic AI 渗透带来的需求上升，国产价格有望提升至海外的 30%–50%。这是中国大模型公司未来最确定的收入增长来源之一——不是卖得更多，是卖得更贵。

03 / 前沿实验室

OpenAI 与 Anthropic：同样的技术，相反的财务曲线

这是全世界最贵的两家 AI 公司，也是商业结构差别最大的两家。一家把订阅卖给 9 亿人，一家把 API 卖给企业——结果先摸到盈亏平衡的是后者。

OpenAI：C 端订阅规模全球第一，亏损也全球第一

OpenAI 的收入曲线本身就是这个行业最陡的一条：2026 年 2 月年化约 250 亿美元，8 月突破 400 亿美元，9 月底向投资者私下披露年化接近 500 亿美元，年底目标 700 亿美元。

口径冲突 · 40% 的差距

同一时点（2026 年 9 月底）存在两个数字：OpenAI 私下披露的接近 500 亿美元，与同期媒体仍广泛引用的逼近 700 亿美元。相差 40%。可能源于统计范围、收入确认方式，或关联方收入（算力信用额度计入营收）的处理差异。两个数字都来自私下披露、均未经审计，而这条直接决定其估值基础。本报告并列呈现，不作取舍。

收入结构上，OpenAI 是订阅主导：超过 65% 来自 C 端订阅，个人订阅约占 40%。但 CFO 向股东披露的一个转折值得注意——企业收入已经超过 ChatGPT。也就是说，它正在悄悄向 Anthropic 的结构靠拢。

成本侧才是问题所在。2026 年预计经营亏损 140 亿美元，现金消耗约 170 亿美元，其中推理成本单项就有 141 亿美元。折算下来：每赚 1 美元，亏 1.22 美元，预计 2030 年才盈利。

拖累毛利率的结构性因素是免费用户。OpenAI 有 9 亿以上免费用户，每人每月成本约 0.70 美元，合计拖累毛利率 20–30 个百分点。这是「C 端规模第一」的代价——规模在这里不是优势，是负债。

算力侧的承诺规模同样惊人：合计超过 1.4 万亿美元——Oracle 超 3,000 亿、Azure 2,500 亿（至 2032）、AWS 约 1,380 亿、Stargate 5,000 亿。2026 年 5 月 22 日它保密递交了 S-1，原目标 9 月上市、估值 8,520 亿至 1 万亿美元，后推迟至 2027。与微软的独家授权协议正在重新谈判，Stargate 也从「自建」转向「转租」。

Anthropic：纯 B2B API，反而先转正

Anthropic 的收入曲线更陡：2025 年底约 90 亿美元 → 2026 年 5 月 470 亿 → 2026 年 7 月底突破 650 亿美元。2026 Q2 单季营收超 115 亿美元。不到一年增长逾 7 倍。

它的结构与 OpenAI 正好相反：75%–85% 来自企业级 API 调用，订阅只占 15%，个人订阅仅 5%。增长的核心变量是 Claude Code——它把调用从「单次对话」变成了「持续消耗 Token 的工作流」。这正是第 02 节里 API 利润率高于订阅的那个机制在真实业务上的体现。

更值得注意的是企业市场的份额已经反转：34.4% 的美国企业为 Anthropic 付费，OpenAI 为 32.3%；企业 LLM 市场份额 Anthropic 32%、OpenAI 25%。Anthropic 借道 AWS Bedrock 和 Azure Foundry 分发需要支付约 20% 的收入分成，但换来了更低的获客成本——这是一笔算得过来的交易。

它的效率指标也在改善：每兆瓦算力产生的 ARR 从 1,600 万美元提升到预计 6,000 万美元。市场给出的定价是：预计 10 月以约 2 万亿美元估值上市，PS 约 30.8 倍。

这一节的核心

两家公司的技术能力处于同一梯队，但财务曲线完全相反。差别不在模型，在卖给谁、按什么单位收钱。OpenAI 卖订阅给 9 亿人，其中绝大多数不付费却产生成本；Anthropic 卖 API 给企业，用多少付多少，成本完整转嫁。巴克莱测算的「API 推理利润率 80% vs 订阅 70%」这个 10 个百分点的差距，在规模上被放大成了「一个还在年亏 140 亿，一个已经季度盈利」。

04 / 云厂商

Amazon 与 Google：这条价值链上唯一稳定赚钱的一环

如果第 02 节的结论是「模型公司在替云厂商打工」，那这一节要看的就是：这个「雇主」到底赚了多少，以及它的收入里有多少是真的。

Google：云增速 82%，但四成积压订单来自一家自己投资的公司

Alphabet 2026 Q2 总营收 1,198 亿美元（+24.23%），营业利润 407.7 亿美元，利润率 34%。其中 Google Cloud 营收 247.68 亿美元，同比 +82%，营业利润同比 +212%，利润率 35.6%。云占总营收比重从去年同期的 14% 升到 20% 以上。

最刺眼的数字是云积压订单首次突破 5,000 亿，达 5,140 亿美元。但拆开看：Anthropic 一家承诺五年内向谷歌云支付约 2,000 亿美元、采购 5GW 的 TPU 算力，占这笔积压订单的 40% 以上。而谷歌同时是 Anthropic 14% 的股东，承诺投资至多 400 亿美元，芯片还指定为自家 TPU。

成本侧：Q2 资本支出 449.24 亿美元（同比翻倍），2026 全年指引从 1,800–1,900 亿上调至 1,950–2,050 亿美元，2027 年还将「显著增加」。Q2 自由现金流为 −58.55 亿美元。融资动作包括增发 496 亿美元、发行 203 亿美元高级无担保债券、筹备 400 亿美元 ATM。

模型侧的进展是 Gemini App 月活 9.5 亿，每分钟处理 220 亿 API Token，近 90% 的财富 100 强采用 Gemini Enterprise。云市场份额从 12% 提升到 14%。

Amazon：唯一给出 AI 单独口径的云厂商

AWS 2026 Q2 营收 422.3 亿美元（+36.7%），是 2021 年以来 18 个季度里最快的增速，连续五季加速；年化运行率 1,690 亿美元。营业利润率 39.4%，是三大云里最高的。AWS 占 Amazon 营收约 21%，却贡献了 60% 以上的营业利润。

关键的一点：Amazon 是三家里唯一给出 AI 单独口径的——AI 业务与自研芯片业务的年化运行率各突破 250 亿美元，均三位数增长。这让它成为唯一可以真正横比的样本。谷歌只披露云总营收，微软口径更杂，直接横比会失真。

自研芯片在这里是财务事件而非技术事件：Trainium2 性价比优于同类 GPU 约 30%，已基本售罄；Trainium3 再提升 30–40%，产能几乎订满。Jassy 称大规模部署 Trainium 每年可省下数百亿美元 capex，并带来数百个基点的营业利润率优势。2026 年资本开支指引从 2,000 亿上调至 2,200 亿美元，且他明确表示「即使到这个水平，2026 年仍产能不足，2027 年同样」。

绑定关系上，Anthropic 追加投资至多 250 亿美元、使用 100 万颗以上 Trainium2、锁定 5GW；OpenAI 也承诺消耗约 2GW 的 Trainium——即在微软之外，OpenAI 同样向亚马逊买算力。Bedrock 走的是另一条路：不做自研模型垄断，做多云托管市场，积压订单 4,960 亿美元创新高，且尚未计入 Anthropic 那笔 1,000 亿美元以上的协议。

最重要的一条：循环交易

云厂商的「AI 收入暴涨」里，有相当大一块不是终端需求，而是循环交易。机制是：云厂商投资实验室 → 实验室拿这笔钱承诺采购该云厂商的算力 → 云厂商把采购承诺计入积压订单。

谷歌云 5,140 亿积压订单里 Anthropic 占 2,000 亿（40%+），而谷歌同时是 Anthropic 的股东、投资人、芯片供应商——四个角色叠在一起。亚马逊的 4,960 亿积压订单里，Anthropic 与 OpenAI 的承诺同样是主要构成。

所以看到「AI 收入暴涨」，必须问三个问题：① 这钱是不是来自自己投资的公司？② 记的是「已确认收入」还是「积压订单」？③ 是「云总营收」还是「其中 AI 部分」？三个问题里任何一个不澄清，这个数字就不能用来做判断。

05 / 中国大厂

阿里、字节、腾讯：三种活法，和三种透明度

这三家都在做 AI，但「AI 收入」这个词在它们财报里的含义完全不同——一家写进财报，一家只在内部定目标，一家混进游戏和广告。

阿里：三家里唯一被财报直接验证的路径

字节：从「把 Token 做成独立生意」降格为「基础业务」

这是本报告里最值得注意的一次叙事转向。字节 2026 年的 MaaS 目标是 150 亿元（2025 年底定的还是 100 亿，且几乎每月上调）——而 2025 年全年 MaaS 收入只有约 15 亿元，也就是说 2026 年的目标是一年前的 10 倍。增长几乎全部来自 Seedance 2.0，单月营收超 10 亿元；Token 日均消耗量保持月度近 40% 的增速。

但 2026 年 6 月 23 日，梁汝波罕见现身 FORCE 大会，说了一句很关键的话：「火山 MaaS 业务正在变成字节的基础业务，我们的投入将长期且坚定。」同时宣布三年价格战收官，叙事从「低价破局」转向「生产质变点、产业价值、全栈能力」。

为什么「独立生意 → 基础业务」是实质性后退

「独立生意」意味着这门业务要自己承担盈亏、证明单位经济性；「基础业务」意味着它是基础设施，可以长期投入、不必短期算账。措辞的变化，把 MaaS 从「要交卷的业务」重新定位成了「要长期补贴的底座」。结合字节净利率从 2023 年的 26%、2024 年的 21% 降到 2026 年的约 16.7%，这个转向是可以理解的。

字节同时在自研芯片上加码：SeedChip 与三星洽谈代工，计划 2026 年前产出 10 万颗自研 AI 推理芯片。

腾讯：三家里商业化最不透明的一家

腾讯是唯一不把大模型单独立成收入项的公司，它把 AI 塞进微信、游戏、广告这些已经跑通的现金流业务。2026 年它第一次把账单部分摊开：Q1 为 AI「补交」88 亿元，单季 AI 投入约 370 亿元。

但透明度问题依然存在，有三个具体表现：

  • 收入只能倒推。至今不单列 AI 收入，只能通过「剔除新 AI 产品影响后的经营利润」反推——2026 Q2 剔除 AI 影响后 Non-IFRS 经营利润增速从 9% 提升到 19%，这是倒推口径，不是披露口径。
  • 表述自相矛盾。关于算力出租，业绩会出现过「不准备出租算力」与「算力出租是安全垫」两种相反说法，均无一手原文可核。
  • AI 收入被混入游戏与广告。AI 提效计入既有业务，无法剥离出 AI 本身的单位经济性。

不过有一条新信息值得记下：腾讯云收入增速从 Q1 的同比高十几加速到 Q2 的低二十几，官方归因于 AI 相关需求、国际扩张及通用云使用量与定价提升。这说明腾讯也在赚「卖云」的钱，只是不在财报里单独说。业绩会口径还提到 WorkBuddy 付费用户毛利率「相当不错」。

高盛给腾讯的重新定价理由很能说明问题：「模型之外，14 亿用户才是更深的护城河。」——这正是第 01 节「不单卖」那一类的价值所在。

06 / 中国挑战者

Kimi、DeepSeek、MiniMax、智谱：四家都在卖 Token，毛利差 4 倍

这四家常被放在一起比较，但它们的毛利率差距大到不像同一个行业。而差距的来源不是定价，是推理成本。

DeepSeek：毛利率全行业最高，定价却全行业最低

这是本报告里最反直觉的一组数字。2026 年 1–7 月，DeepSeek 营收 4.75 亿元（约为 2025 年全年的 10 倍），净亏 7.15 亿元。但它的 整体毛利率 44.6%，API 业务毛利率高达 82.9%。

对照一下：82.9% 的 API 毛利率，高于 OpenAI 的整体毛利率（约 39%），是智谱 API 分部（24.6%）的 3.4 倍。而 DeepSeek 的定价是全行业最低的——V4-Pro 输出 Token 在引入峰谷计费后为高峰 3.96 美元、非高峰 1.98 美元每百万 Token，对照 Kimi K3 的 15 美元、Claude Opus 5 的 25 美元。

这意味着它的成本结构可能是中国唯一能撑住价格战的。高毛利来自推理基础设施优化——用更少的芯片跑同样的模型。这也印证了中金第 02 节的那个判断：参数规模小、专注推理优化的厂商在同等算力卡上有更优的推理效率。

风险在支出侧：AI 基建支出从 2025 年的 12 亿元暴增到 2026 年前 7 个月的 110 亿元，接近 10 倍。6 月完成首轮融资 500 亿元，二轮再募 500 亿元、投前估值 5,000 亿元，科创板 IPO 目标 2027 年挂牌。那个 82.9% 的毛利率能不能在 110 亿基建砸下去之后守住，是接下来最该盯的数。

智谱：用毛利率腰斩换来的「API 转型成功」

智谱是中国大模型公司里唯一把两条路线都完整走过一遍的样本，也因此最能说明换轨的代价。

读这张表的正确方式不是「API 转型成功」。86.5% 的 API 占比，是靠主动砍掉毛利率 48.8% 的私有化业务换来的——那条线的毛利率是 API 的两倍。整体毛利率因此从 50.0% 腰斩到 26.4%。这不是升级，是换轨。

运营侧有一组很有意思的数字：Token 调用量较年初 +40 倍，单位推理成本较年初 −80%，但 API 均价反而 +101%——低价 Flash 放量、Coding 订阅与大客户拉高了均价。智谱自述的路径是「卖模型 → 卖调用 → 卖订阅 → 卖端到端任务结果」。

资金上，2026 年 7 月按 1,588 港元/股配售募资约 314 亿港元。但销售费用增速远超收入——销售成本 +635.4%，说明获客成本正在吃掉规模效应。市值峰值时 P/S 曾超 500 倍。

MiniMax：B 端占比一年翻倍，但毛利率四家里最低

MiniMax 的底色是海外 C 端产品，但 2026 年上半年发生了一次结构性翻转：

  • FY2025 营收 7,900 万美元（+158.9%），73.0% 来自中国大陆以外，AI 原生应用占 67.2%，销售费用反而 −40.3%（典型产品驱动）
  • 2026H1 收入 1.1657 亿美元（+283.1%，已超 2025 全年），B 端占比从 30.3% 翻转到 63.4%（+703.1%），C 端仅 +100.9%
  • B:C 从 3:7 翻转为 7:3

但毛利率是四家里最低的：整体毛利率 17.9%（较上年 +5.7 个百分点），研发 2.97 亿美元（+138.8%），经调整净亏损 2.93 亿美元、同比扩大 111.2%。另有一项外部风险：迪士尼、环球、华纳起诉 Hailuo AI，索赔金额可能达 7,500 万美元。

月之暗面：估值涨最快，商业模式最新

Kimi 的 Pre-IPO 融资已完成，估值约 500 亿美元，计划 2027 年 Q1 赴港 IPO，目标年销售额 20 亿美元。

但真正值得记的是一个新信号：它正在与微软、亚马逊、谷歌洽谈 Kimi K3 的收益分成协议——也就是把开源权重变成向云厂商收成的通道。这是「开源商业化」的第二个样本（第一个是阿里的 Qwen 分成计划）。如果这条路走通，开源模型第一次有了独立于云的收入来源。

三条从这张表里读出来的结论

第一，毛利率与收入规模无关，与「卖什么」有关。OpenAI 年化收入约 500 亿美元，是 DeepSeek 的百倍量级，但毛利率低 5 个百分点以上。规模没有带来单位经济性的改善——因为它的规模建立在 9 亿免费用户之上。

第二，中国公司之间 4 倍的毛利差距，来自推理效率而非定价。DeepSeek 定价最低、毛利最高（82.9%）；智谱和 MiniMax 定价更高、毛利更低。这直接反驳了「中国模型公司只能靠低价内卷」的判断——真正拉开差距的是单位推理成本，也就是工程能力。

第三，订阅和私有化部署都是「看起来稳、其实拉低毛利」的收入。OpenAI 的订阅结构拉低毛利率（免费用户成本 + 重度用户消耗）；智谱的私有化部署毛利率 48.8%，看起来不错，但相对 API 的理想值仍是拖累，且人力密集、回款周期长（应收账款曾占营收 47%）。

一个统一的解释

把第 02 节和第 07 节合起来看，这个行业的毛利率排序其实由一件事决定：收入是否与成本同比例增长。API 按量计费，用多少付多少，成本完整转嫁——所以毛利最高。订阅是固定价格面对变动成本，重度用户吃掉利润。私有化部署是固定价格面对固定人力成本，规模不经济。免费用户是纯成本、零收入。

凡是「定价与消耗脱钩」的模式，毛利都会被侵蚀。这是这份报告里最可迁移的一条结论。

08 / 五个分歧

这个行业真正在争的五件事

分歧一：订阅和 API，哪个更值钱？

证据站在 API 一边，但市场定价站在订阅一边。巴克莱的测算是 API 推理利润率超 80%、订阅约 70%；Anthropic 靠纯 API 结构先转正，OpenAI 靠订阅结构年亏 140 亿。但 OpenAI 的估值目标（1 万亿美元）一度高于 Anthropic（2 万亿）——不过 2026 年这个关系已经反转。

这个分歧的实质是：订阅买的是「用户关系」，API 买的是「成本转嫁」。前者在获客成本高企时更贵，后者在价格战时更脆。目前还没有定论。

分歧二：开源到底怎么赚钱？

三个样本，三条不同的路，都还没跑完：

  • 阿里：开源引流 → 卖云。目前唯一被财报验证的（AI 收入占比破 30%，云 +45%）
  • 月之暗面：把开源权重变成向云厂商收成的通道——正与微软、亚马逊、谷歌洽谈 Kimi K3 收益分成
  • DeepSeek：开源 + 极低定价，靠推理效率撑住 82.9% 的 API 毛利

共同点是：没有一家靠「卖模型权重」赚钱。开源的变现全部发生在模型之外——云、分成、或者效率优势带来的成本领先。

分歧三：卖模型还是卖云？

第 02 节的数字给了倾向性答案：模型公司每 100 美元收入，35–40 美元流向云厂商。如果这个分配比例稳定，那么「卖云」在结构上优于「卖模型」。

但有一个反例：DeepSeek 的 API 毛利率 82.9%，意味着它的推理成本被压到极低，它在很大程度上绕开了这个分配。方式是自建基建（110 亿元投入）加上推理优化。这条路很重，但如果成立，它就是唯一能跳出「替云厂商打工」的模型公司。

分歧四：AI 一定要独立盈利吗？

腾讯和 Google 给出的答案是不需要。腾讯把 AI 塞进游戏（单季 659 亿元）和广告（435.7 亿元）；Google 塞进搜索与广告，整体营业利润率 34%。它们不需要回答「AI 业务什么时候盈利」，因为 AI 的作用是让主业更快。

这可能是这个行业里最被低估的一种优势：当竞争对手还在为 AI 的独立单位经济性挣扎时，这一类公司已经在用 AI 改善现金流了。高盛给腾讯的重新定价理由就是这句话——「模型之外，14 亿用户才是更深的护城河」。

分歧五：云厂商的 AI 收入，有多少是真的？

这是最需要警惕的一条。循环交易让「AI 收入」这个数字部分失真。谷歌云 5,140 亿积压订单里 40% 以上来自 Anthropic，而谷歌同时是 Anthropic 的股东、投资人和芯片供应商。

判断方法在第 04 节已经给出：问三个问题——钱是否来自自己投资的公司、记的是已确认收入还是积压订单、是云总营收还是其中 AI 部分。亚马逊是唯一能完整回答这三家的（AI 与芯片业务各 250 亿美元以上年化），谷歌只披露云总营收，腾讯完全不披露。

09 / 走向与风险

接下来该盯什么

三个可能的方向

价格战从「降价」转向「提价」。中金认为国产模型定价有望从对标海外的 5%–30% 提升到 30%–50%；字节 2026 年 6 月宣布三年价格战收官；智谱的 API 均价在成本下降 80% 的同时反而上涨 101%。三个独立信号指向同一件事：靠降价换份额的阶段正在结束。如果这个转向成立，中国大模型公司的收入增长会从「量」切换到「价」。

「卖 Token」的赢家会向推理效率集中。既然毛利差距来自推理成本而非定价，那么竞争会从模型能力转向工程效率。自研芯片（Trainium 性价比优 30%、真武 V900、SeedChip）和推理优化（量化、推测解码）的财务价值会超过模型榜单上的名次。

循环交易会被重新定价。当云厂商的积压订单越来越依赖自己投资的公司，市场迟早会开始区分「真实终端需求」和「关联方承诺」。这个区分一旦发生，部分 AI 收入的估值倍数会重构。

主要风险

R1 推理利润率回落 高

巴克莱明确提示，当前 50%–65% 的推理利润率「未来某个阶段仍会出现一定程度的回落」，原因是前沿模型竞争加剧与算力供给增加。整个行业的盈利改善建立在这个利润率能守住的前提上。

R2 资本开支与回报周期错配 最高

阿里单季资本开支 676.78 亿元、Google 2026 指引 1,950–2,050 亿美元、Amazon 2,200 亿美元、OpenAI 算力承诺超 1.4 万亿美元——而吴泳铭说的「AI 算力资本开支三年回本」尚未被验证。三家的自由现金流已同时转负（阿里 −173 亿、腾讯 −138 亿、Google −58.55 亿美元）。如果回报周期长于融资窗口，这个行业会出现系统性的再融资压力。

R3 收入口径不可比 中

OpenAI 同一时点有 500 亿与 700 亿两个年化数字；巴克莱指出收入确认方式（总额法 vs 净额法）的差异会让财务报表可比性越来越低，并类比为 Uber 与 Lyft 的差异。这意味着「谁增长更快」这个判断本身可能建立在不可比的数据上。

R4 版权与合规成本显性化 中

MiniMax 的 Hailuo AI 面临迪士尼、环球、华纳的诉讼，索赔可能达 7,500 万美元——接近其半年收入的三分之二。对毛利率本就很低（17.9%）的公司，这类成本可能是决定性的。

未核实 / 存疑

  • OpenAI 的年化收入——同一时点（2026-09 底）存在 500 亿与 700 亿美元两个数字，相差 40%，均来自私下披露、未经审计。可能源于统计范围、收入确认方式或关联方收入处理。证伪方式：S-1 公开文件。
  • DeepSeek 的 4.75 亿元营收与 82.9% API 毛利率——来自 The Information 的非公开数据，非公司披露，未获交叉验证。这条数字如果成立，是本报告最重要的发现之一，但可信度等级低于港股财报。
  • 字节的 MaaS 目标与实收——150 亿目标与 15 亿实收均来自 36 氪「独家」单源，未能交叉验证。字节未上市，无审计口径。
  • 腾讯「算力出租」的官方立场——业绩会出现过「不准备出租算力」与「算力出租是安全垫」两种相反表述，未能获取一手原文，引用需谨慎。
  • Anthropic 的 63% 毛利率与 Q3 EBIT 超 10 亿美元——为媒体/券商测算与预告口径，非已披露财报。
  • 月之暗面与微软/亚马逊/谷歌的收益分成洽谈——「正在洽谈」阶段，无签约证据，且开源分成模式尚无先例跑通。
  • 智谱市值的时点差异——2026 年 9 月口径约 5,200 亿港元，2026-10-08 口径约 3,135 亿港元，引用须带日期。

未能获取

  • Google Cloud 中 AI 部分的单独收入——障碍：谷歌只披露云总营收，不拆分 AI 贡献。因此本报告无法将 Google 与 Amazon 的 AI 收入直接横比。
  • OpenAI 的绝对毛利率与订阅收入金额——障碍：仅有「免费用户拖累毛利率 20–30 个百分点」的相对表述，无绝对值。
  • 腾讯 AI 收入的具体拆分——障碍：官方不单列，且 AI 提效被混入游戏与广告收入，无法剥离。
  • 火山引擎总营收规模——障碍：仅有 MaaS 子项目标，无整体口径。
  • 三家中国大厂自研芯片的单位成本对比——障碍：属供应链商业机密，无公开一手数据。
  • 微软 Azure 的 AI 收入口径——障碍：本报告聚焦用户指定的 11 家，微软作为 OpenAI 的算力与分发方仅在第 03、04 节作为关系方提及，未做独立调研。
本次调研的方法限制

本报告在 2026-10-13 完成。两项环境限制影响了核实深度：其一，WebFetch 工具被本机网络策略全局拦截，所有网页正文改由命令行直连抓取；其二，本会话检索配额（200 次，所有并行调研共享）在四组并行调研中被大量消耗，部分条目因此未能交叉验证。因此「未能获取」清单中的部分条目，障碍是工具限制而非信息本身不存在，建议后续补查。

另需注意：本报告大量引用券商测算（巴克莱、中金、中信证券、大和、高盛、花旗）。这些测算的假设与方法未经独立验证，引用时应连同机构与日期一起引用。
